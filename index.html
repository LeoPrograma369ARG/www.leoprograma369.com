Aprendizaje: de cero a proyectos reales

El mismo camino que recorro y enseño: no memorizar sintaxis, sino construir. Cada etapa termina en algo publicado: una página, una app, un repo o una plataforma educativa.

Nivel 1 · Base

Fundamentos de la web

HTML5 semántico, CSS (caja, Flexbox, Grid), JavaScript desde variables y funciones hasta el DOM. Primera página real, no un tutorial suelto.

Nivel 2 · Oficio

Diseño, frontend y producto

Maquetación mobile-first, Bootstrap 5, tipografía, color, tema claro/oscuro, i18n ES/EN y UX. De ejercicio a marca usable.

Nivel 3 · Sistema

Backend, datos y automatización

APIs, servidor, Git, GitHub Actions, Azure DevOps, DNS, HTTPS y deploys. Lo que separa un demo de un producto.

Nivel 4 · Escala

SEO, contenido y gran escala

Títulos, meta, canonical, sitemap, robots.txt, Search Console e idiomas. Plataformas educativas y presencia en redes.
