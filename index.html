    Aprendizaje: de cero a proyectos reales

    El mismo camino que recorro y enseño: no memorizar sintaxis, sino construir. Cada etapa termina en algo publicado: una página, una app, un repo o una plataforma educativa.

    Nivel 1 · Base

    Fundamentos de la web

    HTML5 semántico, CSS (caja, Flexbox, Grid), JavaScript desde variables y funciones hasta el DOM. Cómo funciona un navegador, un servidor y un dominio. Primera página real, no un tutorial suelto.

    Nivel 2 · Oficio

    Diseño, frontend y producto

    Maquetación mobile-first, Bootstrap 5, tipografía, color, tema claro/oscuro, componentes, i18n (ES/EN) y UX. El sitio deja de ser un ejercicio y pasa a ser una marca usable en celular y escritorio.

    Nivel 3 · Sistema

    Backend, datos y automatización

    APIs, lógica de servidor, persistencia, Git de verdad (ramas, PRs), GitHub Actions, Azure DevOps, DNS, HTTPS y deploys continuos. Lo que separa un demo de un producto que se actualiza solo.

    Nivel 4 · Escala

    SEO, contenido y gran escala

    Títulos, meta, canonical, sitemap, robots.txt, datos estructurados, Search Console. Arquitectura de información para plataformas educativas, varios idiomas y presencia en YouTube, GitHub y redes.

    Método

    Aprender haciendo y enseñando

    Proyecto propio desde el día uno. Documentar, grabar, publicar. Enseñar obliga a ordenar ideas: por eso AprenderGratis.io y el contenido en redes son parte del aprendizaje, no un extra.

    Para quién

    Sin barreras de entrada

    Quien empieza de cero, quien ya maqueta y quiere backend/SEO, o quien necesita un producto real (portafolio, plataforma educativa, portal de contenido). El nivel se ajusta al proyecto, no al ego del stack.
